# Hardware contribution area

The repository currently contains only schematic and PCB image exports recovered from the report. Add native design sources rather than recreating them from screenshots.

## Expected additions

- Native KiCad project under `kicad/`.
- BOM with manufacturer part numbers and tolerances under `bom/`.
- Enclosure CAD, dimensions, and fabrication notes under `enclosure/`.
- Wiring diagram for the final Vero-board prototype.
- Range-switch truth table and connector pinout.
- Power-rail and battery-protection documentation.

Every hardware revision should have a clear identifier and matching schematic, PCB, BOM, and firmware configuration.
